Pico-8 Game Collection

These are all the games I created using the game engine Pico-8. It uses the coding language Lua, the music and SFX are all done within it's own editor, and the art is entirely 8-bit with a fixed 16 color palette. As it is best used for smaller less complex games, this is a collection of all of the shorter games I have created using it.
