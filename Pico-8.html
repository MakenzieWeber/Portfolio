Pico-8 Game Collection

These are all the games I created using the game engine Pico-8. It uses the coding language Lua, the music and SFX are all done withing it's own editor, and the art is entirely pixel art due to it being modeled after 8-bit hardware/gaming systems. As it is best used for smaller games, all of these are shorter more simplistic games.
